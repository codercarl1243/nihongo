## System Overview
The "nihongo" project is a comprehensive TypeScript and Rust application designed to facilitate the learning of Japanese language skills, particularly targeting JLPT levels. It leverages a modern tech stack, including Vite for the frontend build process, Tauri for creating a cross-platform desktop application, and Rust for backend services. The application is structured as a backend service, with error codes, logging utilities, and type-safe result handling. The dominant architectural patterns observed are the use of the Result pattern for handling operations that can succeed or fail, the utility function pattern, and a client-server architecture for managing user interactions, language processing, and TTS generation. The application includes a utility library for string sanitization and error handling, and it utilizes natural language processing (NLP) models and text-to-speech (TTS) technology to facilitate interactive language learning sessions. Additionally, the project appears to use a microservices architecture with a sidecar service running alongside the main application to provide additional functionality. The sidecar application, built with Python and FastAPI, provides three main functionalities: Automatic Speech Recognition (ASR), Language Learning Model (LLM) chat, and Text-to-Speech (TTS). It uses FastAPI for the web server, Uvicorn as the ASGI server, and several custom ML libraries (`mlx-lm`, `mlx-audio`) for handling ASR, LLM, and TTS tasks. The dominant architectural pattern observed in the sidecar application is the Model-View-Controller (MVC) pattern, where the `models.py` file acts as the model layer, `server.py` as the controller, and the API endpoints serve as the view. The frontend is built using React, and the application likely includes features such as vocabulary quizzes, grammar exercises, and interactive lessons. The project also has a design system focused on styling and theming web components, using CSS for styling and following a modular architecture where styles are divided into distinct layers: variants, appearance, and paint. The project leverages CSS custom properties (variables) to manage color themes and apply styles conditionally based on data attributes. The project also includes an audio processing library written in Rust, specifically the `audio_engine` crate, which captures audio input from the microphone, resamples it to a consistent 16kHz mono stream, and performs real-time Voice Activity Detection (VAD) to segment speech into "turns." The dominant architectural pattern observed in the audio processing library is a producer-consumer model, where the audio engine produces clean audio data that can be consumed by external transcribers. Additionally, the project includes a Rust-based component for database operations using SQLite, managed through the rusqlite library and serde for serialization.
