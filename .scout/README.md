# .scout/

Knowledge base artifacts generated by [scout](https://github.com/codercarl1243/tools).
Nothing in this folder is hand-written.

## Requirements

**scout must be installed on your machine** before any of the commands below will work.
It provides both the `scout` pipeline and the `kb` query tool.

- Repo: https://github.com/codercarl1243/tools
- Dependencies: Node.js, Python 3.11+, Ollama (for rebuilds), chromadb, sentence-transformers

Once installed, build the local vector index for this project:

```bash
kb index ~/projects/codercarl/nihongo
```

This is fast and incremental — run it after code changes to keep search results current.

## Files

- **architecture.md** — AI-generated overview: modules, responsibilities, data flow.
  Commit this. Share it. Feed it to an LLM as project context.
- **dependencies.json** — static dependency graph (nodes = files, edges = imports).
  Consumed by `kb` to enrich vector search results with module labels.
- **data/** — ChromaDB vector index. Gitignored — rebuilt locally by `kb index`.
- **_repomix_raw.xml** — raw repomix dump used for compilation. Gitignored.

## Semantic search

```bash
kb query nihongo "how does authentication work"
kb query nihongo "where are API routes defined" --k 8 --fmt json
```

## Regenerating

```bash
# Full rebuild (repomix + Ollama + vector index) — slow, do this when architecture changes
scout ~/projects/codercarl/nihongo

# Re-index only (fast, incremental — run after code changes)
kb index ~/projects/codercarl/nihongo
```
